🔐 Generador de contraseñas en Python

Mi primer generador de contraseñas hecho con Python.

Empecé haciendo una primera versión utilizando random, pero después aprendí que para generar contraseñas es mejor utilizar el módulo secrets, ya que está pensado para generar valores difíciles de predecir.

¿Qué hace?

El programa:

Pregunta cuántos caracteres quieres.
Comprueba que la cantidad sea válida.
Permite entre 1 y 100 caracteres.
Genera caracteres aleatorios.
Utiliza secrets para la generación.
Construye y muestra la contraseña final.

Cómo ejecutarlo

Necesitas tener Python instalado.

Después ejecuta:

python generador.py

El programa te preguntará cuántos caracteres quieres y generará la contraseña.
